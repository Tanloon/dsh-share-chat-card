# Changelog

All notable changes to this project are documented in this file. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-11-26

### Added

- Share pill in the composer dock that opens a record picker with live preview.
- Export selected records as paginated PNG images, as one self-contained HTML page, or straight to the clipboard.
- Stats header: record count, tool calls, turn time, span, and tokens when assistant steps report usage.
- Toggles for reasoning blocks and timestamps; Chinese and English copy.
